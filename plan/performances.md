The herd app will allow you to turn a composition into a performance, but this requires several levels of coordination. First, we a matchmaking system like a video game. A host would need to be able to choose a composition that was already defined in the system loaded up in initiate a performance mode. It would probably go into a pre-show holding pattern, where you have something like a matchmaking server that allows people to join synchronizes the timing of their devices like a network time server. And the host would be have the ability to start the performance to move from that initial gathering phase into the first program of the composition.
